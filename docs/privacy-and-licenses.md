# ข้อมูลใบหน้า PDPA และ license ของโมเดล

ฟีเจอร์ระบุตัวตนพนักงานทำให้ Camwell เก็บข้อมูลที่กฎหมายคุ้มครองเข้มที่สุดประเภทหนึ่ง
ส่วนโมเดลของระบบ YOLOv8 มีเงื่อนไขการใช้เชิงพาณิชย์ที่ระบบ MediaPipe ไม่มี

## ข้อมูลใบหน้าเป็นข้อมูลอ่อนไหว

ฟีเจอร์ระบุตัวตนใช้ face descriptor (embedding) และรูปที่ลงทะเบียน
ข้อมูลทั้งสองแบบเป็นข้อมูลชีวภาพ (biometric data) ซึ่ง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) ของไทยนับเป็นข้อมูลส่วนบุคคลที่มีความอ่อนไหว

ก่อนใช้งานจริงกับพนักงาน องค์กรต้องมีสามเรื่องนี้ แต่ละข้อบอกว่าระบบรองรับไว้แค่ไหน

1. **ขอความยินยอมอย่างชัดเจนก่อนลงทะเบียนใบหน้า**
   การลงทะเบียนด้วยมือในทั้งสองระบบบังคับให้ติ๊กยืนยันก่อน
   `POST /api/employees` ของ camwell-backend ปฏิเสธคำขอที่ไม่มี `consentGiven: true`
   แต่การลงทะเบียนอัตโนมัติของระบบ MediaPipe เก็บใบหน้าโดยยังไม่มีความยินยอม
   การลงทะเบียนอัตโนมัติคือ `POST /api/employees/identify` ที่ส่ง `autoEnroll: true` และเปิดอยู่เป็นค่าเริ่มต้น
   ปิดได้ที่ช่อง "ลงทะเบียนใบหน้าที่ไม่รู้จักอัตโนมัติ" ในแผงตั้งค่าของหน้ากล้อง
2. **แจ้งวัตถุประสงค์การใช้ข้อมูลให้ชัดเจน และเก็บเท่าที่จำเป็น**
   หน้าแรก `/` อธิบายว่ากล้องดูอะไร เตือนเมื่อไร และเรื่องความเป็นส่วนตัว
3. **ให้พนักงานขอลบข้อมูลของตัวเองได้ตลอดเวลา**
   ระบบ MediaPipe ลบได้ที่ `/?people` แผงรายชื่อในหน้ากล้อง และเมนู People ใน Dev Console
   ระบบ YOLOv8 ลบได้ที่ `/?yolo-dashboard=people` และเมนู "ใบหน้า" ใน YOLO Console

ระบบยังไม่ผ่านกระบวนการขอความยินยอมที่ถูกต้องตามกฎหมายครบทุกขั้นตอน **ปรึกษาฝ่ายกฎหมายหรือ HR ก่อนใช้งานจริง**

## ข้อมูลใบหน้าเก็บที่ไหน

ระบบ MediaPipe เก็บ descriptor ไว้ที่ camwell-backend (SQLite) เท่านั้น และไม่ส่ง descriptor กลับมาที่เบราว์เซอร์หลังลงทะเบียน
ระบบ YOLOv8 เก็บรูปที่ลงทะเบียนไว้ที่ `yolo-backend/data/faces/<ชื่อ>/` บนเครื่องที่รัน yolo-backend

## ปิดฟีเจอร์ใบหน้า

ถ้ายังไม่พร้อมเรื่องความยินยอม ปิดฟีเจอร์ใบหน้าได้ทั้งสองระบบ

- ระบบ MediaPipe ปิดที่ช่อง "ฟีเจอร์ใบหน้า" บน header ของ Dev Console
  หรือช่อง "เปิดใช้ความเหนื่อยล้า, ระยะห่างจากจอ และการระบุตัวตน" ในแผงตั้งค่าของหน้ากล้อง
- ระบบ YOLOv8 ปิดด้วยตัวแปร `FACE_ENGINE=off` ตอนเปิด yolo-backend

ทั้งสองระบบใช้ใบหน้าวัดระยะห่างจากจอและความเหนื่อยล้าด้วย ปิดฟีเจอร์ใบหน้าแล้วสองหมวดนี้จึงหยุดทำงานไปด้วย

## license ของโมเดล

ระบบ MediaPipe ใช้เฉพาะโมเดลที่ license อนุญาตให้ใช้ในซอฟต์แวร์เชิงพาณิชย์แบบปิดได้
MediaPipe ใช้ Apache 2.0 และ face-api ใช้ MIT

ระบบ YOLOv8 ต้องตรวจ license ก่อนใช้เชิงพาณิชย์

- `ultralytics` ซึ่งเป็นแพ็กเกจของ YOLOv8 ใช้ AGPL-3.0 ซอฟต์แวร์ปิดต้องซื้อ Enterprise License จาก Ultralytics
- โมเดลใบหน้า InsightFace `buffalo_l` ใช้ได้เฉพาะงานวิจัยที่ไม่ใช่เชิงพาณิชย์ ตาม docstring ของ `InsightFaceEngine` ใน `yolo-backend/face_id.py`
- ทางเลือกคือ YuNet กับ SFace จาก OpenCV Model Zoo ซึ่ง license อนุญาตให้ใช้เชิงพาณิชย์
  ตั้ง `FACE_ENGINE=sface` แล้ววาง `face_detection_yunet_2023mar.onnx` และ `face_recognition_sface_2021dec.onnx` ไว้ใน `yolo-backend/`

ค่าเริ่มต้น `FACE_ENGINE=auto` เลือก InsightFace ก่อนเสมอถ้าติดตั้งไว้
ถ้าต้องการใช้เชิงพาณิชย์ ให้ตั้ง `FACE_ENGINE=sface` ให้ชัด อย่าปล่อยเป็น `auto` บนเครื่องที่ลง insightface ไว้
ผลของแต่ละค่าอยู่ในหัวข้อ "ตัวแปรสภาพแวดล้อม" ของ [ระบบ YOLOv8](yolo.md)
