# ระบบ YOLOv8

ระบบ YOLOv8 ประมวลผลที่ yolo-backend ซึ่งเป็น FastAPI ที่พอร์ต 8000
frontend เรียก yolo-backend ผ่าน `/yolo/...` ทั้ง REST และ WebSocket
Vite ตัด `/yolo` ออกแล้วส่งต่อไปที่ `http://127.0.0.1:8000` ตามที่ตั้งไว้ใน `frontend/vite.config.ts`

วิธีติดตั้งและเปิด yolo-backend อยู่ใน [README](../README.md)

## หน้า

| URL | หน้า |
|---|---|
| `/?yolo-dashboard` | หน้าของเจ้าหน้าที่ มี 7 หน้า |
| `/?yolo-console` | YOLO Console สำหรับนักพัฒนา |

## หน้าของเจ้าหน้าที่ (`/?yolo-dashboard`)

แถบเมนูด้านบนมี 7 หน้า ชื่อเมนู ลำดับ และ URL กำหนดไว้ที่ `YOLO_PAGES` ใน `frontend/src/yoloDashboard/pages.ts`
การเปลี่ยนหน้าไม่โหลดหน้าเว็บใหม่ WebSocket และกล้องที่กำลังส่งภาพจึงทำงานต่อ
เมื่อมีคนล้ม แถบแดงพร้อมเสียงเตือนขึ้นบนสุดของทุกหน้า จนกว่าจะกด "รับทราบเหตุการณ์"

| เมนู | URL | เนื้อหา |
|---|---|---|
| ภาพรวม | `?yolo-dashboard` | ผังห้องพร้อมคนในห้อง ตารางคนในห้อง และส่วน "ภาพจากกล้อง" ส่วน "ภาพจากกล้อง" เลือกแหล่งภาพได้ห้าแบบ คือ ไฟล์วิดีโอ ไฟล์รูปภาพ กล้อง browser go2rtc และ Simulator เมื่อเข้าหน้านี้ ระบบเปิดกล้อง browser ให้เอง ยกเว้นตอนที่กำลังวิเคราะห์แหล่งอื่นอยู่ |
| เกณฑ์แจ้งเตือน | `?yolo-dashboard=camera` | เปิด ปิด และปรับเกณฑ์ของแต่ละหมวด และเปิดโหมดทดสอบได้ |
| พื้นห้องและโซน | `?yolo-dashboard=floor` | วางมุมพื้นบนภาพจากกล้องเพื่อแปลงตำแหน่งเป็นเมตร แล้วแบ่งโซน |
| รายชื่อบุคคล | `?yolo-dashboard=people` | ลงทะเบียนใบหน้าจากไฟล์หรือกล้องหลังติ๊กความยินยอม ลบรูป ลบคน ปรับเกณฑ์จับคู่ใบหน้า และดูคู่ที่หน้าคล้ายกัน |
| ประวัติแจ้งเตือน | `?yolo-dashboard=alerts` | กรองตามช่วงวัน คน และหมวด ส่งออก CSV ได้ |
| รายงานประจำวัน | `?yolo-dashboard=report` | ความเสี่ยง Office Syndrome รายคน กราฟรายชั่วโมง และการ์ดรายคนที่บันทึกเป็น PNG หรือคัดลอกได้ ส่งออก CSV หรือ JSON และพิมพ์ได้ |
| สถิติการใช้ห้อง | `?yolo-dashboard=rooms` | สรุปทุกรอบที่วิเคราะห์จบแล้ว ได้แก่ จำนวนคน ช่วงที่คนเยอะที่สุด เวลาในแต่ละท่าทาง และเวลาในแต่ละโซน |

## เกณฑ์แจ้งเตือน

ค่าเริ่มต้นอยู่ที่ `WellnessSettings` ใน `yolo-backend/wellness.py`
ค่าในโหมดทดสอบอยู่ที่ `TEST_MODE` ใน `frontend/src/yoloConsole/wellness.ts` โหมดนี้ย่นเวลาให้เห็นการเตือนครบทุกหมวดในหนึ่งถึงสองนาที และไม่ได้มีไว้ใช้งานจริง
ชื่อหมวดในตารางตรงกับที่หน้าเว็บแสดง

| หมวด | เตือนเมื่อ (ค่าเริ่มต้น) | โหมดทดสอบ |
|---|---|---|
| ท่านั่ง | นั่งท่าไม่ดีเกือบตลอด 30 วินาที | 5 วินาที |
| ระยะจอ | หน้าใหญ่กว่าขนาดปกติ 1.25 เท่า ต่อเนื่อง 30 วินาที ระบบเรียนรู้ขนาดหน้าปกติจากเวลานั่ง 120 วินาที | 5 วินาที เรียนรู้ 20 วินาที |
| เวลานั่ง | นั่งต่อเนื่อง 45 นาที การลุกหรือออกไปนาน 60 วินาทีนับเป็นการพัก และเริ่มนับใหม่ | 1 นาที พัก 15 วินาที |
| ความล้า | หลับตา 2 วินาที หรือหาว 3 ครั้งใน 10 นาที นับเป็นการหาวเมื่อริมฝีปากด้านในห่างกันเกิน 0.30 เท่าของความกว้างปาก ค้างไว้ 1.5 วินาที | หลับตา 1.5 วินาที หรือหาว 1 ครั้ง ค้างไว้ 1 วินาที |
| การล้ม | ศีรษะร่วงลงหาเท้าอย่างน้อยครึ่งหนึ่งของความสูงตัว ภายใน 1 วินาทีหลังจากตัวตั้งตรง แล้วระบบเห็นคนนั้นในท่านอน 3 ครั้งภายใน 0.5 วินาที ท่านอนคือลำตัวเอียงจากแนวตั้ง 60° ขึ้นไป หรือกรอบตัวกว้างกว่าสูงโดยไม่ชนขอบภาพ | เท่าค่าเริ่มต้น |
| การล้ม | ศีรษะร่วงลง 35% ของความสูงตัวภายใน 0.6 วินาที แล้วหายไปกลางภาพภายใน 1.5 วินาที และไม่กลับมาอย่างน้อย 0.3 วินาที คนที่ออกทางขอบภาพไม่นับ หน้าเว็บแสดงเป็น "สงสัยหกล้ม: ร่วงแล้วหายจากภาพ" | เท่าค่าเริ่มต้น |

ค่าที่ปรับจากหน้าเว็บเก็บใน `yolo-backend/data/wellness_settings.json`
`yawn_ratio` เปลี่ยนชื่อเป็น `yawn_open` และ `fall_drop` เปลี่ยนชื่อเป็น `fall_head_drop` เพราะวัดคนละแบบกับเดิม
`WellnessSettings.from_dict` ข้ามค่าของชื่อเก่าใน `wellness_settings.json` ระบบจึงใช้ค่าเริ่มต้นใหม่แทน

### วัดความแม่นยำกับคลิปจริง

`clip_eval.py` เทียบท่านั่ง ยืน และเดินที่ระบบตัดสินกับป้ายที่ทำด้วยมือใน `yolo-backend/tests/clip_labels.json` และนับการล้มที่ไม่ควรเกิด
`fall_eval.py` วัดการล้มกับ UR Fall Detection Dataset ซึ่งมีคลิปล้ม 30 คลิปและคลิปกิจวัตรทั่วไป 40 คลิป สคริปต์โหลดชุดข้อมูลเองตอนรันครั้งแรก ชุดข้อมูลนี้ใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์
ทั้งสองไฟล์เก็บผล YOLO ไว้ใน `yolo-backend/data/eval_cache/` เมื่อแก้โค้ดส่วนหลัง YOLO การวัดใหม่จึงใช้เวลาไม่กี่วินาที

`clip_labels.json` อ่านคลิปจาก `../resource/` ซึ่งนับจาก `yolo-backend/` คือ `camWell/resource/`
camWell ไม่มีโฟลเดอร์นี้ ก่อนรัน `clip_eval.py` ให้คัดลอก `example clip.mp4` `example clip 2.mp4` `example clip 3.mp4` และ `example clip 4.mp4` จากโฟลเดอร์ `resource/` ของ repo Cam-Well-YoLo-ByteTrack มาไว้ที่ `camWell/resource/`
`.gitignore` ของ camWell ไม่ได้กันไฟล์ `*.mp4` คลิปทั้งสี่ไฟล์จึงขึ้นเป็นไฟล์ใหม่ใน `git status`

```bat
cd yolo-backend
.venv\Scripts\python.exe clip_eval.py
.venv\Scripts\python.exe clip_eval.py --clip c4 --sheet data\eval_cache\sheet
.venv\Scripts\python.exe fall_eval.py
```

`--sheet` สร้างภาพรวมทุก 2 วินาที แต่ละภาพมีกรอบที่ระบบเห็นพร้อมท่า และจุดขาวตามป้าย ใช้ดูว่าระบบตัดสินผิดที่ใครและตอนไหน

## ตัวแปรสภาพแวดล้อม

yolo-backend อ่านตัวแปรเหล่านี้ตอนเริ่ม ใน `yolo-backend/app/config.py`

| ตัวแปร | ค่าเริ่มต้น | ผล |
|---|---|---|
| `FACE_ENGINE` | `auto` | เลือกโมเดลจดจำใบหน้า ดูตารางถัดไป |
| `ROOM_DATA_DIR` | `yolo-backend/data` | โฟลเดอร์เก็บข้อมูลทั้งหมด |
| `ROOM_FACES_DIR` | `<ROOM_DATA_DIR>/faces` | โฟลเดอร์รูปที่ลงทะเบียน |

`create_engine` ใน `yolo-backend/face_id.py` เลือกโมเดลตาม `FACE_ENGINE` ดังนี้

| ค่า | ผล |
|---|---|
| `auto` | ใช้ InsightFace ถ้าติดตั้งไว้ ถ้าไม่ได้ติดตั้งจะใช้ SFace ถ้าไม่มีไฟล์ onnx ของ SFace การจดจำใบหน้าจะปิด |
| `insightface` | ใช้ InsightFace ถ้าไม่ได้ติดตั้ง การจดจำใบหน้าจะปิด |
| `sface` | ใช้ YuNet กับ SFace ถ้าไม่มีไฟล์ onnx การจดจำใบหน้าจะปิด |
| `off` | ปิดการจดจำใบหน้า |

SFace ต้องใช้ไฟล์ `face_detection_yunet_2023mar.onnx` และ `face_recognition_sface_2021dec.onnx` ใน `yolo-backend/`
InsightFace เก็บโมเดล `buffalo_l` ไว้ที่ `%USERPROFILE%\.insightface`

## ไฟล์ข้อมูล

ข้อมูลของระบบ YOLOv8 อยู่ใน `yolo-backend/data/`

| ไฟล์หรือโฟลเดอร์ | เก็บอะไร |

## YOLO Console (`/?yolo-console`)

YOLO Console เป็นหน้าสำหรับนักพัฒนา เข้าจากปุ่ม "Console" บนแถบเมนูของ `?yolo-dashboard`
ปุ่ม "← Back to Dashboard" พากลับไป `?yolo-dashboard` โดยไม่หยุดการวิเคราะห์
ปุ่ม Engine ใน sidebar สลับไป Dev Console ของระบบ MediaPipe ได้ การสลับหยุด session ของ YOLO ก่อน แล้วเปลี่ยนทั้งหน้า

เมนูด้านซ้ายมี 6 หน้า กำหนดไว้ที่ `TABS` ใน `frontend/src/yoloConsole/YoloConsole.tsx`

| เมนู | เนื้อหา |
|---|---|
| หน้าหลัก | เลือกแหล่งภาพ ภาพสด แผง "คนในห้องนี้" แผงสถิติ heatmap ผังพื้น และปุ่มควบคุมการเล่น |
| ตั้งค่า | calibrate พื้นและแบ่งโซน ปรับเกณฑ์แจ้งเตือนและโหมดทดสอบ |
| ใบหน้า | ลงทะเบียนคนจากไฟล์รูปหรือถ่ายจากกล้อง browser หลังติ๊กความยินยอมตาม PDPA ปรับเกณฑ์จับคู่ และดูคู่ที่หน้าคล้ายกัน |
| ประวัติการแจ้งเตือน | กรองตามวัน คน และหมวด ส่งออก CSV ได้ |
| รายงานประจำวัน | ความเสี่ยง Office Syndrome รายคน กราฟรายชั่วโมง และการ์ดรายคนที่บันทึกเป็น PNG หรือคัดลอกได้ ส่งออก CSV หรือ JSON และพิมพ์ได้ |
| รายงาน | รายงานของทุก session ที่จบแล้ว และดาวน์โหลด `tracks.csv` ได้ |

รายละเอียดของหน้าหลักมีดังนี้

- แหล่งภาพมีห้าแบบ คือ ไฟล์วิดีโอ ไฟล์รูปภาพ กล้อง browser go2rtc และ Simulator
- ภาพสดแสดงกรอบคนพร้อมชื่อจากใบหน้า กรอบสิ่งของ และเส้นทางเดิน กรอบคนมี ⚠ เมื่อคนนั้นมีการเตือน
- แผง "คนในห้องนี้" แสดงท่านั่ง ระยะห่างจากจอ เวลานั่ง ความเหนื่อยล้า และการหกล้ม พร้อมเสียงเตือน เมื่อมีคนล้ม แผงนี้มีปุ่มรับทราบ
- ปุ่มควบคุมการเล่นได้แก่ หยุดชั่วคราว เลื่อนคลิป จบ และเริ่มใหม่

หน้าตั้งค่าบันทึกค่าลงสองไฟล์

- calibrate พื้นด้วยการลากมุมทั้ง 4 แล้วแบ่งโซน คลิกบนเส้นกรอบเพื่อเพิ่มจุด ค่านี้บันทึกลง `yolo-backend/data/settings.json`
- เกณฑ์แจ้งเตือนและโหมดทดสอบบันทึกลง `yolo-backend/data/wellness_settings.json`

## โครงสร้างโค้ด

```
frontend/src/yoloDashboard/       หน้าของเจ้าหน้าที่ 7 หน้า แถบเมนู YoloNav และ CSS ของตัวเอง (yd-*)
frontend/src/yoloConsole/         YOLO Console และโมดูลที่หน้าของเจ้าหน้าที่ใช้ร่วม:
                                  yoloService (REST และ WebSocket ไป yolo-backend), useYoloLive, store, types,
                                  wellness, drawLive, คณิตศาสตร์พื้นห้อง (homography, floorCalibration, zoneLayout)
yolo-backend/app/main.py          FastAPI: REST ใต้ /api และ WebSocket ที่ /ws/live
yolo-backend/app/config.py        path ของข้อมูล origin ที่อนุญาต และตัวแปรสภาพแวดล้อม
yolo-backend/room_analytics.py    YOLOv8 และ ByteTrack
yolo-backend/face_id.py           จดจำใบหน้า
yolo-backend/wellness.py          แจ้งเตือนสุขภาพและค่าเริ่มต้นของเกณฑ์
yolo-backend/data/                ข้อมูลของระบบ YOLOv8
```
