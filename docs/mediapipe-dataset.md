# เก็บ dataset ท่านั่ง

Dataset Recorder ของระบบ MediaPipe เก็บตัวเลข landmark และ feature โดยไม่เก็บภาพ เพื่อใช้ปรับจูนเกณฑ์ท่านั่ง
label ที่เลือกได้และรูปแบบไฟล์ export อยู่ในหัวข้อ "Dataset Recorder" ของ [ระบบ MediaPipe](mediapipe.md)

## ก่อนเริ่ม

- เปิด frontend ด้วย `npm run dev` ระบบเก็บ sample เฉพาะตอนรัน dev และ production build ไม่เก็บ
- **ถ้ารีเฟรชหรือปิดแท็บ ข้อมูลที่ยังไม่ Export จะหาย** แท็บเก็บข้อมูลไว้ในหน่วยความจำเท่านั้น
- หน่วยความจำเพิ่มขึ้นเรื่อยๆ ระหว่างบันทึก อัดเป็นช่วงแล้ว Export ทีละช่วง
- dataset หนึ่งชุดใช้ได้กับรุ่นโมเดลเดียว ระบบล็อกรุ่นตาม sample แรก
  ถ้ารุ่นที่เลือกไม่ตรงกับรุ่นที่ล็อกไว้ ระบบไม่ให้เริ่มบันทึกจนกว่าจะ Export แล้วกด "ล้างข้อมูล"
- การแจ้งเตือนยังทำงานระหว่างอัด ถ้าเสียงรบกวน ให้ปิดช่อง "เสียงแจ้งเตือน" บน header ของ Dev Console
  การบันทึกไม่มีผลกับการตรวจจับและการแจ้งเตือน

## บันทึกท่าทุก label

1. เปิด `/?console` แล้วติ๊กช่อง "Dataset Recorder" บน header แผงบันทึกจะขึ้นในหน้า Monitor
   ถ้าอยากใช้หน้ากล้อง `/?camera` แทน หน้านั้นมีแผงแบบง่ายที่แสดงเฉพาะตอนรัน dev
2. เลือกกล้อง
3. ให้คนเดียวนั่งหน้ากล้อง ระบบเก็บเฉพาะเฟรมที่มีคนเดียว
4. เลือก label `GOOD` แล้วกด "เริ่มบันทึก"
   ภาพของกล้องที่กำลังบันทึกจะมี `● REC` และค่า 4 feature ซ้อนอยู่
5. นั่งท่านั้นต่อเนื่อง 30 ถึง 60 วินาที แล้วกด "หยุดบันทึก"
6. ทำข้อ 4 และข้อ 5 ซ้ำกับ `FORWARD_HEAD`, `SLOUCH`, `LEAN_LEFT` และ `LEAN_RIGHT`
7. กด "Export JSON"

## เก็บข้อมูลให้ใช้งานได้

- อัด `GOOD` ก่อนทุกรอบ เพื่อใช้เป็น baseline ตอนวิเคราะห์
- เก็บจากหลายคนและหลายวัน dataset แบบนี้ใช้ได้ดีกว่าการอัดคนเดียวนานๆ
- อย่าย้ายกล้องหรือเปลี่ยนรุ่นโมเดลกลางคัน
