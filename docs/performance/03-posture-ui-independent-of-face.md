# 03: ฟีเจอร์ท่านั่ง/เตือนพักใช้ได้โดยไม่ต้องเปิดฟีเจอร์ใบหน้า

**What to build:** ผู้ใช้เปิดแอปครั้งแรกโดยไม่ต้องรัน backend ก็ใช้ฟีเจอร์ท่านั่งและเตือนพักได้ครบ: ฟีเจอร์ใบหน้าปิดเป็นค่าเริ่มต้น (เพราะตอนนี้ต้องพึ่ง backend), รายชื่อคนในแต่ละกล้องแสดงเสมอ, สไลเดอร์ของเตือนพักย้ายออกมาจากกล่องที่ซ่อนตามสวิตช์ใบหน้า และมีสไลเดอร์ใหม่ "รีเซ็ตเวลานั่งเมื่อหายไปนาน" (`breakResetMs`, หน่วยนาที 1–15)

**Blocked by:** 01

**Status:** ready-for-agent
